# 影視數據儀表板 — 視覺重設計準則

> 本文件是重新設計的唯一依據，交由執行者（人或 AI）落地。
> 若與 `CLAUDE.md` 的舊色彩 tokens 衝突，**以本文件為準**，並在完工後同步更新 `CLAUDE.md`。
> 不變的工程約束仍然有效：inline `CSSProperties`、不引入 CSS framework、不裝新套件、繁體中文文案、TypeScript strict。

---

## 1. 設計方向：資料新聞／印刷報表風（Editorial Data Journalism)

整體氣質向 **財經報紙的數據版面**（FT、日經、聯合報系資訊圖表）靠攏，而不是 SaaS 儀表板：

- **資訊優先**：畫面上每一個像素都在傳達資料或協助閱讀資料，沒有裝飾性元素。
- **字體排印驅動層級**：靠字號、字重、灰階深淺區分層級，不靠色塊和卡片。
- **細線與留白分區**：用 1px 淺灰細線（hairline）和留白劃分區塊，取代圓角卡片。
- **克制的單一強調色**：Netflix 紅只在小面積出現（品牌、目前選取狀態），其餘一律墨色與灰階。

### 1.1 禁止清單（本次要移除的「AI 生成感」樣式）

執行時**逐條檢查**，以下樣式一律不得出現：

| 禁止 | 取代方案 |
|---|---|
| 深藍紫底色（`#0a0a16`、`#111124`）+ 紫色強調（`#7c6fff`） | 紙白底 + 墨黑字（見 §2） |
| 漸層背景、毛玻璃（glassmorphism）、發光陰影（glow） | 純色、無陰影；分區用細線 |
| 大圓角卡片（radius 12px）鋪滿畫面 | 去卡片化；必要容器 radius 0–2px |
| Pill 藥丸按鈕（radius 20px、半透明底） | 方正文字型控制項（見 §5.2） |
| Emoji 當圖示（🏆 🥧 🇹🇼 等） | 純文字標籤或色點（見 §5.4） |
| box-shadow 浮起卡片 | 不用陰影；tooltip 允許一層極淡陰影 |
| 每個區塊都有粗體大標題 + 底線 | 小型大寫/小字標題（見 §3 層級） |

## 2. 色彩 Tokens（完整替換舊 palette）

### 2.1 基底與文字

| Token | 值 | 用途 |
|---|---|---|
| `paper` | `#fcfcfb` | 頁面背景（帶一點暖的紙白） |
| `paper-raised` | `#f5f4f1` | 表頭列、Sidebar 背景、hover 底色 |
| `ink` | `#1a1a18` | 主要文字、主要數字 |
| `ink-secondary` | `#55544f` | 次要文字、圖表軸標籤 |
| `ink-muted` | `#8a8984` | 輔助說明、停用狀態 |
| `rule` | `#e3e1dc` | 一般分隔細線（1px） |
| `rule-strong` | `#c9c7c0` | 主要分區線、表格外框 |
| `accent` | `#e50914` | Netflix 紅。僅限：品牌標誌、目前選取／active 狀態、被選取節目的高亮。**永不當作圖表資料色** |
| `accent-wash` | `rgba(229,9,20,0.06)` | 選取列底色 |

規則：
- 除上表與 §2.2 類型色之外，**不得引入任何新的 hex 值**。
- 強調紅在任何一個畫面中的出現面積應低於 5%——它是「指出目前焦點」的墨水，不是主題色。

### 2.2 類型（Genre）資料色 — 已通過色盲與對比驗證

九個類型的專用色。前八色已以 OKLab 驗證：色盲（protan/deutan/tritan）相鄰可辨、正常視覺可辨、對紙白底對比 ≥ 3:1。`其他` 為中性灰（分類學上的「摺疊桶」，允許低彩度）。

**固定順序**（圖例順序、堆疊順序、相鄰性都依此，不得依數值重排）：

| # | 類型 | 色值 | 備註 |
|---|---|---|---|
| 1 | 韓劇 | `#b3302b` | 磚紅（刻意與 accent 紅 `#e50914` 區隔） |
| 2 | 美劇 | `#3568b0` | 藍 |
| 3 | 陸劇 | `#b07d10` | 赭黃 |
| 4 | 動畫劇 | `#7b5cb8` | 紫 |
| 5 | 日劇 | `#c4527e` | 玫紅 |
| 6 | 台劇 | `#1f6f3f` | 深綠 |
| 7 | 實境秀 | `#c67612` | 橙 |
| 8 | 英劇 | `#0d9488` | 藍綠 |
| 9 | 其他 | `#9a9a94` | 中性灰 |

規則：
- 顏色**跟著類型走**，篩選後倖存的類型不得換色。
- 更新 `src/constants/genres.ts` 的 `GENRE_COLORS`；語意延續舊版（韓＝紅、台＝綠、陸＝黃、動畫＝紫……），唯英劇由紅改為藍綠（舊值與韓劇衝突）。
- Sidebar 內的 `RELEASE_COLORS`、`COLORS` 等散落的臨時色陣列一併清理，改引用本表或灰階 tokens。

## 3. 字體排印

字型堆疊維持 `src/index.css` 現況（PingFang TC / Microsoft JhengHei），**不引入 webfont**。層級全部用字號＋字重＋灰階做，不用顏色做。

| 層級 | 規格 | 用途 |
|---|---|---|
| 頁面標題 | 17px / 700 / `ink` | Header 站名 |
| 區塊標題 | 12px / 700 / `ink-secondary` / `letterSpacing: 1` | 各區塊小標（小型標題，不加底線） |
| 資料主體 | 13px / 400 / `ink` | 表格、清單內容 |
| 關鍵數字 | 依場景 15–24px / 700 / `ink` | 積分、名次 |
| 輔助說明 | 12px / 400 / `ink-muted` | meta 資訊、註腳 |

數字規則（排行榜產品的核心）：
- 所有數值一律 `fontVariantNumeric: 'tabular-nums'`，確保縱向對齊。
- 排名第 1–3 名可用較大字級（如 15px/700）突顯，其餘同級；**不要**用獎牌 emoji 或金銀銅色。
- 千分位以 `toLocaleString()` 呈現。

## 4. 版面與間距

- 基本單位 4px 不變；區塊內距收斂為 `16px 20px`；區塊之間**不留 margin 卡片間隙**，改以 1px `rule` 細線相接。
- 整體結構（Header 60px、左 Sidebar、右內容區、三分頁）**維持不變**——本次是視覺重造，不是資訊架構重造。
- 圓角：容器 0px；tooltip 與小徽章最多 2px。
- 排行榜類內容盡量**表格化**：欄位對齊、表頭一列（`paper-raised` 底、12px/700/`ink-secondary`）、列與列之間 1px `rule` 分隔、列 hover 底色 `paper-raised`、選取列底色 `accent-wash` ＋ 左側 2px `accent` 邊。

## 5. 元件準則

### 5.1 Header
- 白底（`paper`）、底部 1px `rule-strong`。
- 保留紅色「N」方塊標誌（radius 2px）；站名 17px/700 `ink`。
- 統計期間為 12px `ink-muted`；「首尾週資料可能不完整」警示改為純文字加「※」前綴，不做黃色小膠囊。

### 5.2 篩選控制項（取代 pill 按鈕）
所有篩選（年份、季度、月份、類型、發行模式、Netflix 篩選）統一為**文字型 segmented control**：

- 選項橫排，`gap: 0`，每項 `padding: 4px 10px`，12px 字。
- 未選取：`ink-secondary`、透明底、無框。
- 選取中：`ink` + 700 字重 + 底部 2px `accent` 底線（或選取項白底＋1px `rule-strong` 外框，擇一全站統一）。
- hover：文字轉 `ink`。
- 多選（類型篩選）：選項前加 8px 色點（該類型色），選取時色點實心、文字 `ink`；未選取時色點空心（1px 該色描邊）、文字 `ink-muted`。

### 5.3 Sidebar 導覽
- `paper-raised` 底、右側 1px `rule-strong`。
- 三個分頁改為純文字項目：13px，選取中 700/`ink` ＋ 左側 3px `accent` 邊條；未選取 `ink-secondary`。移除 emoji。

### 5.4 圖示政策
- 全站禁止 emoji 與 icon 套件。
- 類型識別 = 8px 圓色點 ＋ 文字標籤（`GENRE_ICONS` 廢棄或改輸出空字串，元件端移除引用）。
- 狀態註記（警示等）用文字符號：「※」「—」「▲」「▼」。

### 5.5 Tooltip
- 白底 `#ffffff`、1px `rule-strong` 框、radius 2px、`padding: 8px 12px`、13px/`ink`。
- 允許唯一一處陰影：`0 2px 8px rgba(26,26,24,0.10)`。
- 內容格式：首行節目名 700，其下「標籤　值」兩欄對齊，數值 tabular-nums。

## 6. 圖表準則（Recharts 與 ECharts 通用)

1. **軸與格線退隱**：軸線 `rule-strong`、刻度文字 11–12px `ink-secondary`；格線 `rule` 且只留與閱讀方向垂直的一組（橫向 bar 只留縱格線）；不畫圖表外框。
2. **Bar**：直接用類型色實心填色，不用漸層、不用圓角膠囊 bar（radius ≤ 2px）；相鄰 bar 或堆疊段之間留 2px `paper` 間隙。
3. **折線（走勢圖）**：線寬 2px；資料點預設不畫，hover 時顯示 ≥ 8px 圓點；名次軸反轉（第 1 名在上）維持現況。
4. **直接標籤優先**：Top 20 這類 bar chart 直接在 bar 端標數值（12px `ink-secondary`），不依賴圖例；折線圖若 ≤ 4 條線，線尾直接標節目名。
5. **圖例**：≥ 2 個系列必有圖例；樣式 = 色點 + 文字（12px `ink-secondary`），置於圖表上方一列，不用 ECharts/Recharts 預設樣式。
6. **單一數值軸**：不得出現雙 Y 軸。
7. **圓餅圖**：兩張圓餅維持，但：類型依 §2.2 固定順序排列、扇區間 2px 白縫、標籤拉線 11px `ink-secondary`、不用陰影與 3D。若佔比 < 3% 合併進「其他」。
8. **河流圖（ThemeRiver）**：層順序依 §2.2 固定順序；透明度一律 100%（不做半透明疊色）。
9. **hover 為預設互動**：所有圖表都要有 tooltip（§5.5 樣式）；點擊選取節目的行為維持現況，選取高亮用 `accent`。
10. 文字永遠用文字 tokens（`ink` 系列），**不得**把類型色用在文字上；顏色由旁邊的色點或色塊承載。

## 7. 執行與驗收

1. 逐檔改寫：`src/constants/styles.ts`（tokens 重寫）→ `src/constants/genres.ts` → `layout/` → `charts/`。`SECTION_STYLE`／`SECTION_TITLE`／`TOOLTIP_STYLE`／`PILL_BTN` 的**名稱與用法可改**（例如 `PILL_BTN` 更名為 `SEGMENT_BTN`），但共用樣式必須仍集中在 `styles.ts`。
2. 每完成一個分頁跑 `npm run build`（tsc strict，未用的 import 是編譯錯誤）。
3. 驗收清單：
   - [ ] 全站找不到 §1.1 禁止清單中的任何樣式（可 grep：`#0a0a16`、`#111124`、`#7c6fff`、`borderRadius: 12`、`borderRadius: 20`、emoji）。
   - [ ] 三個分頁在 1440×900 與 1920×1080 下無跑版、無水平捲軸。
   - [ ] 類型色與 §2.2 完全一致，且篩選後顏色不重排。
   - [ ] 所有數字 tabular-nums 對齊。
   - [ ] 強調紅只出現在：標誌、active 狀態、選取高亮。
4. 完工後更新 `CLAUDE.md` 的 Color Tokens 與樣式常數章節，使其與本文件一致。
